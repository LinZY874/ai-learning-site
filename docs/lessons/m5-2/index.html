Agent与自动化

解锁 WorkBuddy 高级能力

打造可自动运行的 AI 工作底座

第一节｜给 AI 换专业身份

01｜专家的能力

同样是分析销售数据，专家会先问：这份分析要帮你做什么决定？

拿到一份销售数据，通用 WorkBuddy 可以读数、出图、总结趋势。领域专家则有一套更明确的工作顺序：先理解业务目标、定核心指标，再查数据是否可靠，接着找异常、分析原因，最后给建议。

写小红书文案也一样。除了写好正文，领域专家还会检查选题和标题、开头能否留住读者、产品推荐是否有说服力，以及是否贴合平台和方便互动。

专家 = 人格化的 Skill。 可以理解为：给可复用的做法加上岗位、工作方法和工具，让 AI 持续按这个岗位的要求处理任务。

02｜挑对做事方式

任务越复杂，越需要明确的方法和分工。

从一次性小任务到复杂项目，WorkBuddy 有四种做事方式，各自增加的组织方式不同：

  • 普通任务：通用理解与执行，适合一次性的、说得清的任务。
  • Skill：可复用的操作方法或工具能力，适合反复执行某个固定动作。
  • 专家：岗位身份、工作方法加工具链，适合某个领域的专业问题。
  • 专家团：多位专家配协作流程，适合需要拆解、并行、汇总的复杂项目。

普通任务能完成，就先用普通任务。需要专家团时，再检查四件事：有没有遗漏的工作、哪些步骤必须依次做、哪里需要你确认、最后由谁汇总。分工清楚，协作才接得上。

03｜召唤现成专家

先召唤一个现成专家试做，需要多个岗位配合时再用专家团。

召唤单个专家：打开「专家·技能·连接器」，从内容创作、数据分析、升学考试这些现成专家里选一个，点召唤，然后把任务直接交给它。

召唤专家团：专家团在单独的「专家团」入口里召唤。团长负责拆解任务、分派给不同的专家，最后汇总出一份完整方案。

专家技能连接器列表

04｜创建自己的专家

把岗位和经验说清楚，expert-manager 会替你造一个专属专家。

  1. 创建专家聊天框：依次点击「我的专家」「创建专家」，系统会调用 expert-manage skill，打开创建专家的对话。
  2. 说清岗位与经验：告诉 expert-manager 专家负责什么岗位、服务什么场景、按什么方法做事。
  3. 生成并注册专家：它把要求写成专家档案，校验后注册进「我的专家」。
  4. 召唤使用：回到「我的专家」，像调用其他专家一样把活派给它。

第二节｜把外部工具接进来

01｜接入连接器

连接器负责让 AI 访问外部工具；先找官方连接器，没有对应的再自定义。

这里列出了腾讯文档、腾讯会议、QQ 邮箱、TAPD 等常用工具。要连接未内置的工具，点右上角「自定义连接器」，按引导填写地址和凭证，并限定它能访问的范围。

连接器列表

02｜连腾讯文档发公告

先写出公告草稿，再上传到腾讯文档，方便继续编辑。

  1. 授权腾讯文档：在连接器里完成一次授权。
  2. 生成活动公告草稿：让 WorkBuddy 按活动信息写出公告，得到一份 .md 草稿。
  3. 上传到腾讯文档：在草稿右上角的「上传」菜单里选「腾讯文档」。
  4. 云端创建成功：示例公告出现在腾讯文档里，包含标题、活动基本信息表和议程表。打开检查这些内容后，就可以接着修改。

腾讯文档里的活动公告

03｜接入自己的模型

积分不够，或想调整使用成本，可以接入外部 API 或本地模型。

接外部 API：从设置进入「模型」，点「添加模型」，选择提供商并填写 API Key，也就是调用模型的访问凭证。这里可以接 coding plan 或自定义 API，例如 DeepSeek 的接入需要填写 API Key。

接本地模型：在本机运行，数据留在本机，可以离线使用，也没有按 Token（模型处理的文本单位）计费的成本。

看住凭证：API Key 能用于调用模型，保管好它，不要放进公开材料。

第三节｜手机派活，电脑干活

01｜扫码绑定微信助理

微信扫码绑定后，先试一条只读取信息的指令，确认手机和电脑已经连通。

  1. 助理设置：打开设置里的助理入口。
  2. 微信助理集成：进入配置页。
  3. 微信扫二维码：用手机微信扫描生成的二维码。
  4. 确认已绑定：状态显示已绑定后，先发一条只读取信息、不修改内容的测试指令，确认连接可用。

助理让你在手机的即时通讯软件里发指令，由电脑上的 WorkBuddy 执行。它支持微信、企业微信、微信小程序、QQ、钉钉和飞书。飞书、钉钉的配置较多：要在开放平台创建自建应用、加机器人，只开任务所需的权限，建议先用测试群验证。

微信助理绑定二维码

02｜手机派活，本机验收

同一条任务，手机上发出，电脑上执行，两端实时同步。

在手机微信里给助理发任务，电脑端的同一个对话会同步执行。这样出门时也能派任务，完成后再检查结果是否符合要求。

03｜挑选运行模式

先看任务要不要访问本地文件，再选择本机或云端模式。

模式 任务在哪运行 电脑在线 适合任务
本机模式 已连接的那台电脑 要 本地文件、本地 Skill、已有工作区
云端模式 隔离的云端环境 不要 调研、写作、临时分析

在小程序首页一键切换「云端工作」和「连接电脑」。

第四节｜让任务定时自己跑

01｜自动化的成立条件

先把任务跑稳，再让它定时执行，你才有条件把精力放在验收上。

适合定时执行的任务，通常是「时间固定、步骤相似、结果可检查」的重复工作。交给 WorkBuddy 自动运行前，先准备好五样东西：

  • 明确的触发时间：到点自动开跑。
  • 可重复的输入：每次从同样的来源、按同样的要求取材料。
  • 够具体的提示词：目标和边界说清楚。
  • 受控的工作目录：明确哪些目录能读、哪些能改，避免影响其他文件。
  • 能判断成败的验收条件：写明检查哪些结果，符合要求才算完成。

02｜挑出可自动化的活

用这六个问题检查任务，看看它是否适合定时自动执行。

  • 会重复吗：同样的活反复要做。
  • 输入稳定吗：每次的数据来源一致。
  • 步骤相似吗：流程基本不变。
  • 结果可验收吗：有明确标准，能判断结果对不对。
  • 失败可重跑吗：出错重来没有副作用。
  • 权限可控吗：访问范围限得住。

可以先试「每天 8 点收 10 条某方向的新闻，生成一份简报」。范围小、结果好检查，便于发现问题后调整。

03｜建立自动化任务

到「自动化」页点「添加」，把任务说明和运行时间一起配好。

需要配置名称、工作空间、提示词、模型与技能、定时规则，以及是否推送到小程序。也可以从每日新闻、周报、学习计划等官方模板起步，按自己的来源、时间和交付要求修改。

自动化任务页面

小结

  1. 专家与专家团：专家给 AI 换上专业身份，专家团让一群专家分工协作，交一份完整方案。
  2. 连接器与外部模型：连接器让 AI 够得着外部工具；积分不够时，还能接自己的 API 或本地模型。
  3. 微信助理与小程序：手机派任务，按模式由本机或云端执行，再查看结果。
  4. 自动化任务：先挑一件范围清楚的重复工作，确认输入、步骤和验收标准，再设成定时任务。
