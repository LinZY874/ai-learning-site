AI商业视觉

AI生图：IP 延展

把一张定妆照延展到所有场合，它成了一条产线

第一部分｜延展的共同逻辑

01｜定妆照不够用

只有一张定妆照，IP 就还停在半成品。

定稿和三视图回答的是「它长什么样」，回答不了「它能用在哪」。运营要发朋友圈、设计要做周边、客户要看上墙效果，手里都拿不到能直接用的图。

延展补的就是这一段：让同一个形象会表达、能动、能落地。

02｜四个延展方向

同一张IP底图，能变出四类能直接用的素材。

① 表情包 把喜怒哀乐画在 IP 脸上，用于聊天和互动。

② 动作延展 从站立扩展到挥手、递便签等姿态，用身体动作表达意图。

③ 材质与实景图 把 IP 做成毛绒、陶瓷等材质的周边效果图，再放进真实场景，展示成品的使用效果。

④ 活人感打卡照 把实景照片里的人换成 IP，保留原有的背景、光影和现场感，让它像亲自到场一样自然。

四类的分界在于改变的对象：表情包和动作改的是 IP 当下的状态，材质与实景图和活人感打卡照改的是它以什么形式存在。四类合起来就是一套完整的 IP 视觉资产。

03｜锁造型，改变量

小A 不能变，能变的是它正在做什么。

四套方法共用同一个公式：把参考图当唯一基准锁定造型，再用文字只改一个变量。

锁定的部分：机身比例、奶白方盒配色、屏幕脸双眼、二足短腿、连接方式。这几项每一张图都要重新写清楚，AI 才不会跑偏。

改变的部分：表情、动作、材质、所处场景。一次只改一个。

把满意的结果存成下一张图的基准图：基准越往后越具体，出图越稳。

第二部分｜让 IP 会表达、能动

04｜表情包

只留一张盒子脸

去掉四肢，表情才有地方放。

表情包版本的形态只保留机身，去掉腿脚和手臂。剩下的就是一张会变表情的盒子脸，任何情绪都能直接画在屏幕上。

输出规格固定：1:1 白底九宫格，3×3 九种表情，同一个 IP 只改表情、不改结构。

两条路：文生与图生

想让 AI 自由发挥就走文生，想控制具体表情就走图生。

先上传小A 的角色参考图，再选择表情从哪里来。

① 文生：不额外提供表情参考，用文字安排表情，适合探索不同情绪。

② 图生：额外上传表情参考图，让 AI 把对应情绪套到小A 上。

表情包：文生与图生对照

多出几版再挑

先要数量，再从数量里挑。

AI 很难一次就把九个表情全画对。稳妥的做法是先让它多出几版，从里面挑有用的。

一版九张，出几版就有几十个表情可选。

挑定之后做一次裁剪聚焦，把每一格单独切出来，表情包就大功告成了。

05｜表情包提示词

让AI 就只在表情上动手。

以〔角色图：小A〕为唯一基准锁定造型，只保留机身、不要腿脚手臂；生成 1:1 白底九宫格（3×3，同一 IP 只改表情、不改结构）；背景纯白、排版整齐。

06｜动作延展

先立伸臂态

手臂长什么样，决定后面所有动作能不能做。

手臂在这一步正式定型，后面每一个动作都拿这张图当基准：

  • 从机身中部长出，连接处光滑无过渡
  • 可伸缩、纤细，弱化存在感
  • 非人形手掌，不用五指的手

动作基准：伸臂态设定

以小A 为基准锁定机身比例，长出手臂。从机身中部长出、可伸缩、非人形手掌、纤细、连接光滑无过渡。

手臂是整个形象里唯一需要重新定义的部件，定型之后不再调整。

两种做法与边界

没有把握的动作给参考图，有把握的动作直接描述。

① 纯提示词：直接描述动作，造型交给伸臂态基准图。

② 动作参考图加指令：同时上传伸臂态基准图和姿态参考图，再补一句具体的动作描述。

边界：小A 是二足短腿，蹲下、大跨步这类腿部大幅动作与设定冲突。参考图尽量选比例接近的姿态，避免硬套长腿人物动作。

实例：纯提示词

造型写死在提示词里，只留动作一句在变。

挥手和递便签都只用了一句动作描述，效果很棒。

动作：挥手打招呼与递出便签

以小A 伸臂态的参考图为造型基准，严格保持设计 100% 统一：白色盒状机身、圆角方形屏幕脸 + 深蓝双眼、二足短腿、可伸缩短手。机身比例，腿的长度，严格遵照设定。生成图的动作：〔打招呼 / 递出便签〕。

动作那句写「打招呼」出的是挥手，写「递出便签」出的是手里拿便签，前面整段固定设定原样带上。

实例：参考图引导

给一张姿态参考，AI 就知道你要的是什么幅度。

动作：从参考图到成品

以小A 伸臂态的参考图为造型基准，生成与动作参考图完全一致的小A；动作：复刻参考图姿态，〔补充动作描述〕；纯白背景。

「〔补充动作描述〕」换成下面任一条，就是图里的两个成品：

  • 动作补充描述1（双手举高获胜）：双手举高表达获胜的兴奋，一只脚离地身体摇晃，手臂像参考图一样有折回的弯曲，表情要表达兴奋。
  • 动作补充描述2（撑地后仰看星空）：身子后仰像是仰望星空，手撑在身后，不要撑在身体两旁。

第三部分｜让 IP 落地

07｜材质与实景图

用厂家实拍图定质感

材质的质感，交给厂家实拍图。

“毛绒”“陶瓷”这类词不够具体，可以从 1688 厂家实拍图中选一张质感明确的产品照片作为材质参考。

角色参考用 IP 三视图，让 AI 同时看清正面、侧面和背面的造型与配色。

把周边放进真实场景

客户想看的是周边摆在现场的样子。

做出周边效果图之后，再走一步：把周边放进真实场景。

实景照片越接近目标现场，效果图越能直接拿去讨论。交付时把方案和效果图一起给，客户能看到成品摆在现场的样子，更容易判断是否符合需求。

案例一：毛绒抱枕

从材质参考到落地成品，四张图走完一次交付。

材质参考、周边效果、目标实景、落地成品各一张。毛绒质感参考厂家实拍图，角色配色沿用小A 的设定。

案例：毛绒抱枕落地链路

案例二：车载摆件

同一套流程，换材质和场景就换出一个新品。

银色陶瓷车载摆件沿用同一流程，材质参考从毛绒换成金属质感的陶瓷，目标实景从床换成车内。这个例子还把外观改成银色，需要在材质替换时写明颜色要求。

案例：车载摆件落地链路

08｜落地提示词

材质替换

把材质照片交给 AI，造型配色都不动。

把 IP 三视图作为图一、材质实拍图作为图二。下面的通用提示词适用于保持原造型与配色的任务；银色摆件这类改色案例，需要另写颜色要求。

图一是我的〔IP〕，图二是参考材质（1688 厂家实拍图），生成该材质的效果图，保持造型配色不变。

树脂、玻璃钢、不锈钢、充气都走这一段，只换图二那张材质照片。图一用三视图，造型信息最全。

实景效果

周边做完，再让它进一次真实场景。

图一是我的卡通 IP〔周边，如毛绒抱枕 / 车载摆件〕，将它放入图二的实景。

床、车内、货架这些场景，换图二就行。图一放已经做好的周边效果图，两段提示词连起来就是一次完整交付。

09｜活人感打卡照

把照片里的人换成小A

真人能到的地方，小A 都能到。

真实照片里的人被替换成小A，照片本身的背景、光影和现场感全部留在画面里。

这类照片适合文旅打卡、品牌线下联动，让 IP 成为现场活动的参与者。

实例：两种实景

提示词一个字都不用改，换图就是换场景。

同时上传实景人物照片和小A 的角色参考图，再使用下面的提示词。

保留参考图的背景光影构图不变，把人物换成小A（二足技能盒、屏幕脸双眼、可伸缩手、非人类手掌），模仿原动作，光影自然融合。

置入实景：雪山自拍

置入实景：咖啡馆他拍

让小A 融进画面

特征写得越具体，融合得越自然。

小A 的辨识特征写清楚：二足技能盒、屏幕脸双眼、可伸缩的手、非人类手掌。

避坑：不要找复杂动作、长腿的人物参考图，和小A 的二足短身冲突。

小结

  1. 表情包：做出会变表情的盒子脸九宫格，IP 才算有了自己的情绪。
  2. 动作延展：先立伸臂态，再往外扩动作库，同一张脸能演各种戏。
  3. 材质与实景图：换成真实材质做周边，放进真实场景出效果图，带着落地方案一起交付。
  4. 活人感打卡照：沿用角色特征，选择适合它的动作与照片，持续扩展可用场景。

让每一次满意的结果成为下一次变化的起点。
