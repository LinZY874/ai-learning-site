AI文字创作

AI做商业文案

从产品价值到行动转化

第一部分｜零经验写出两篇鲜明文案

01｜两篇文案

同一份事实材料，AI写出了两种一眼就能分开的吸引力。

下面两张图，是AI为小红书写的零度可乐商业文案，两篇风格差得很远。

  • 1-第一人称体验（健身房日记口吻）
  • 2-场景社交向（聚会订餐时）

02｜用成果管理AI

零经验也能把文案做稳，关键是把每个重要决定变成一份看得见的中间成果。

经验一：让AI一步一交付

零经验最怕一口气拿到终稿，因为很难看出错误从哪里开始。让AI依次交付资料整理、卖点清单、候选文案、审稿报告和修改稿，每一步都可以单独检查；发现问题时回到对应成果修改，已经确认的部分不用推倒重来。

经验二：把关键选择留在人手里

AI找资料、汇总信息都比人快，这些活儿交给它很省事。可哪些表达能放行、哪个版本值得继续做，还得人自己看一遍再定；产品事实里的待核对项也一样，最后是靠实物标签核对才关上的。零经验可以由流程补足，事实确认和最终取舍依然需要人来完成。

经验三：允许方向被淘汰

多版创作的价值在于制造选择。三个方向里，有一个最后没有继续做下去。它的事实表达更干净，可知识密度、语感和行动引导都偏离了这次的任务，继续改的代价接近重写。把它归档之后，精力集中到另外两版上，最后拿到的文案反而更鲜明。

第二部分｜AI商业文案三步法

03｜把写作变成决策

AI写商业文案：“做对一连串选择”。

商业文案很少由某一句漂亮话单独决定。它是一连串彼此牵动的选择：前面选错了，后面写得再顺，也只会更快地偏离目标。

AI把更多可能摆到眼前，也把遗漏、冲突和风险提前暴露出来。人用产品事实和业务目标持续取舍，让每一次选择都指向同一位读者、同一个价值和同一个行动。

04｜AI访谈与提炼

让AI把信息问全

AI动笔前多问一个关键问题，往往能少写一整篇错误文案。

很多人只给AI一个产品名，再补一句“写得有吸引力”。AI会顺着任务往下写，也会把没有说清的地方补成看似合理的细节。文字越流畅，藏在里面的错误越难发现。

把手里的东西全摊开

产品介绍、参数与配料、实物照片、已有反馈和信息来源都可以交给AI。找不到的内容允许标记“待补充”，这个空白比AI临场编出的答案更有价值。

把这次生意说清楚

告诉AI写给谁看、出现在什么场景、发布到哪个渠道、最多写多长，以及最终希望读者查看详情、咨询、报名、购买还是到店。价格、促销和健康表达等特殊边界也要一次讲明。

让AI追问最要命的空白

只问三至五个真正影响文案的问题，优先追问产品版本、核心用户、使用场景、证据来源和渠道限制。问题答完后，AI应该能够说清：为谁写、写什么、在哪里发布、希望读者做什么、哪些话不能说。

建立产品卖点清单

先决定哪些话有资格进入文案，再讨论怎样把它们写得动人。

一条卖点进入文案前，先回答两个问题：谁提供的，能不能核对。AI可以把资料和回答整理成清单，为每条信息保留卖点、来源、可用等级和待核对事项。

有依据，才有资格进文案

产品参数、价格、活动规则和标签信息有明确依据，才具备进入候选稿的条件。数字还要和年份、规格绑在一起。

只有感受，就老老实实写成“我”

口感、气味这类体验没有统一尺度，可以写“我觉得”“我使用时感到”，让感受回到体验者身上。

没有依据，就先拦在门外

互相矛盾、容易构成功效暗示的说法，先留在清单里等待补证。

一句卖点想进文案，先把能核对的依据带上。 包装标签、合同和官方页面能够关闭疑点时，由人核对原件，再让AI把结果写回清单。产品信息、健康表达、法规和标准尤其值得多走这一步。

05｜AI多版创作

先设计版本差异

真正的多版创作，会让每个版本从不同理由推动同一个行动。

多版创作真正值钱的地方，是同一个内容对着不同的人各写一版。三个版本只换标题、形容词和语气，得到的依然是一条路。

先锁住不能变的东西

把已经确认的产品事实、发布渠道和目标行动固定下来。任何版本想加入新卖点，都要先回到卖点清单补证。

再挑一个真正分叉的地方

可以改变读者方向、核心诉求、使用场景或表达身份。需要比较版本时，一次主要改变一个维度，其他条件保持一致，才能看出差异究竟来自哪里。

每个方向先说清“靠什么赢”

写正文前，为每版定下一句话：它从哪里切入，靠哪个卖点打动人，最后推动什么行动。方向从起点就分开，正文才能各说各的理。

多版创作让几版各说各的理，事实和目标行动不变。

写出多版并自检

让AI一边创作，一边交代每句话站在什么依据上。

  1. 逐版成稿：每版都要有适合渠道的标题、正文和行动引导，能够独立拿出来阅读。
  2. 逐版交底：让AI标出事实陈述、主观感受和行动引导，并说明分别来自卖点清单的哪一项。
  3. 当场抓越界：扫一遍禁止表达、待核对数据和突然冒出的新事实，有疑点就标出来。
  4. 证明差异：一句话说清每一版靠什么打动人。标题与正文还能互换，说明方向还没真正拉开。

合格的多版放在一起，应该让人认真比较哪一条更值得留下。

06｜AI模拟审稿

让三种角色找问题

先让AI把掌声收起来，站到读者和审核者的位置挑刺。

一篇文案在作者眼里通常很顺，因为作者知道产品、背景和自己想表达什么。读者没有这些前置信息。模拟审稿的价值，就是提前听见那些发布后才会出现的疑问。

路过的人

他只给你几秒：这是什么，和我有什么关系，要不要接着往下看。

心动但迟疑的人

他已经有点兴趣，可还在犹豫值不值，也怕下一步太麻烦。

事实审核者

他不管文案多动人，只拿卖点清单逐句核对数字、产品名称、规格、效果宣称和待核对内容。

第一轮只收问题，不让AI顺手重写。每条意见写清版本、角色、问题句和原因，问题才不会被一篇新稿悄悄盖住。

模拟审稿先留下问题，别让一篇顺滑的新稿把疑点盖过去。

从问题走到定稿

成熟的审稿会减少版本、关闭问题，并保住已经成立的方向。

先给问题找源头

事实疑点回到卖点清单，方向偏差回到方向卡，措辞歧义留在当前版本处理。找对位置，才能避免为了修一句话把整篇稿改散。

再对着问题精准动刀

按照问题清单逐句修改，每一次修改都要能指向一条具体的审稿意见。

最后把门关上

修改完成后再次检查事实、禁止表达和三个角色的疑问。数字、标签、活动规则等高风险内容由人回到原始材料拍板，确认没有新问题再定稿。

第三部分｜三种文案任务，即拿即用

07｜迁移商业文案方法

文案载体会变，AI提炼卖点、生成多版和模拟审稿这套做法保持不变。

08｜电商产品详情页

让AI把产品功能讲清楚，再把购买理由和下一步行动接起来。

我要为[产品名称]撰写电商产品详情页，目标用户为[用户画像]，希望读者完成[购买／咨询等行动]。产品资料如下：[粘贴产品介绍、参数、价格、用法、注意事项和来源]。

请按以下步骤完成：

  1. 检查资料是否足以写作。缺少会影响产品理解、购买判断或风险提示的信息时，先向我提出不超过5个问题，等我回答后继续。
  2. 建立产品卖点清单，字段为“卖点｜来源｜事实或主观感受｜可直接写、需核对或不能用”。资料没有涉及的内容标注“待补充”，不要自行补写。
  3. 提出三种详情页方向，每种说明目标读者、核心诉求、内容顺序和行动引导。我确认方向后再生成正文。
  4. 按确认方向撰写详情页，包含核心卖点、功能说明、使用场景、规格参数、注意事项和购买指引。完成后分别以初次接触者、犹豫中的用户和事实审核者身份只列问题，再根据问题逐条修改，并附“原文｜改后｜对应问题”对照表。事实描述与效果宣称始终分开表达。

09｜短视频口播脚本

让AI在有限时间里抓住一个卖点，并把语言、画面和行动对齐。

我要为[产品名称]制作一条[时长]的短视频口播，发布平台为[平台]，目标观众为[人群]，希望观众完成[点击、咨询、购买等行动]。产品资料如下：[粘贴产品资料和来源]。

请按以下步骤完成：

  1. 检查产品资料、时长、目标观众和行动要求是否完整。缺少关键信息时先向我提问。
  2. 建立可用卖点清单，区分有依据的事实、只能用第一人称表达的体验和不能使用的说法。
  3. 提出三种脚本方向，每种只选择一至两个核心卖点，并说明开头钩子、证明方式和结尾行动。我确认后再写完整脚本。
  4. 输出“时间段｜口播｜对应画面｜屏幕文字”四列表格，确保正常语速能够在[时长]内说完。完成后分别从首次观看者、犹豫者和事实审核者角度找问题，检查前3秒是否看懂、卖点是否有依据、画面是否支持口播、结尾行动是否明确，再按确认意见定向修改，不引入新事实。

10｜海报与社媒短文案

让AI用更少的字完成识别、理由和行动。

我要为[产品或活动名称]制作[海报／朋友圈／社媒帖子]短文案，目标读者为[人群]，发布场景为[场景]，希望读者完成[报名、到店、咨询、购买等行动]。事实资料如下：[粘贴产品或活动信息、来源和限制]，字数限制为[字数]。

请按以下步骤完成：

  1. 核对名称、时间、地点、价格、规则、产品信息和行动入口。缺少会影响参与或购买的信息时先向我提问，不要自行补写。
  2. 将信息分成“必须出现、可以辅助、不能使用”三类，并说明判断理由。
  3. 生成五组“主标题＋副标题＋行动按钮”文案，分别从直接利益、使用场景、具体事实、情绪共鸣和问题切入。五组必须拥有不同的说服理由。
  4. 以第一次刷到内容的读者和事实审核者身份评价每组文案，检查能否立刻认出对象、理解理由并找到行动入口。推荐最值得保留的两组并说明取舍，在我确认后逐条修改。

11｜固化自己的Skill

把验证过的流程写进Skill，下一次换产品也能从同一套底线开始。

下一次换产品，只需要替换资料、读者、渠道和行动目标；追问、分级、多版和审稿会按照同一套规则重新运行。真正省下来的，是每次从零解释工作方法的时间。

请把下面的工作方法整理成一个可复用的“AI商业文案”Skill：

这个Skill只处理产品详情页、短视频口播、海报和社媒商业文案，不处理新闻稿、合同、医学建议和真实广告投放效果预测。

每次运行时，先读取用户提供的产品资料、事实来源、目标读者、发布渠道、篇幅限制和目标行动。关键信息不足时，提出不超过5个问题，等待回答后继续。

第一阶段建立产品卖点清单，将信息标为“可直接写、只能作为主观感受写、不能用或待核对”。第二阶段基于同一份清单提出三种说服方向，等用户确认后生成多版文案。第三阶段分别以初次接触者、犹豫者和事实审核者身份只列问题，再根据用户选择逐条修改。

全程不虚构产品特性，不把主观体验写成事实，不使用待核对信息，不自行改变价格、时间、规格和活动规则。最终交付卖点清单、方向说明、候选文案、审稿问题、修改对照和定稿。

请输出一份完整的SKILL.md，包含触发范围、所需输入、执行步骤、检查规则、交付格式和不处理事项。规则写成AI可以直接执行的指令，不添加空泛原则。

小结

  1. 先把“好听”和“能说”分开：AI负责把资料问全、把卖点摊开，人决定哪些话有依据、哪些话必须停在清单里。
  2. 让几个方向真正竞争：同一份事实能写出好几个完全不一样的版本，AI负责打开选择，人负责留下最值得继续的方向。
  3. 敢于淘汰，也敢于回头：审稿发现问题就回到对应环节修，方向偏了就归档，事实有疑点就重新核对。

AI让创作更快，让选择更丰富；真正决定文案能否成立的，始终是事实、读者和人的判断。
