说到位，AI才用得上

让每一轮对话都往前推一步

第一部分｜诊断首稿

01｜AI输出的问题

第一稿看着像样，用起来却平庸

上一课学会了交代任务，这一课继续看：首稿方向大致对了，怎样一步步改到能用？

首稿可能格式齐全、要点也在，却仍有套话、缺信息或结构不合适。先找出具体问题，修改才有方向。

一份真实的第一稿

来看一个例子。收到“帮我写一篇蜜雪冰城联名的推广文案”后，AI 交回了下面这篇长文案：

AI 真实输出（未修改）： “🍦❄️ 雪王出街，联名来袭！蜜雪冰城×XXX 梦幻联动，这个夏天甜到上头！❄️🍦 亲爱的雪王粉丝们，期待已久的联名终于来啦！ 这一次，蜜雪冰城携手 XXX品牌，为你带来前所未有的甜蜜体验～不仅有你最爱的经典口味，更有联名限定新品、专属周边，每一口都是心动的感觉！💕 🌟 联名亮点抢先看： 🥤 限定联名饮品 —— 当经典冰淇淋遇上创意灵感，一口下去，双重美味在舌尖碰撞，甜而不腻，清凉解暑！ 🎁 限量联名周边 —— 雪王形象×XXX品牌独家联名杯套、贴纸、帆布袋，数量有限，先到先得，收藏党必入！ 📸 打卡赢福利 —— 到店拍摄联名产品+雪王合影，带话题 #蜜雪冰城联名# 分享至社交平台，即可享受第二杯半价优惠！ 🎉 限时活动：即日起至X月X日 📍 参与方式：全国蜜雪冰城门店同步上线，小程序/到店均可参与 💰 价格亲民：联名款饮品仅需X元起，好喝不贵，快乐加倍！ 这个夏天，和雪王一起解锁甜蜜新体验！赶紧拉上你的小伙伴，一起来蜜雪冰城感受这份独特的快乐吧～💃

蜜雪冰城联名 #雪王出道 #夏日限定 #好喝不贵”

三个AI痕迹

先看句式和关键信息：哪些地方让这份文案还不能直接使用？

  1. 破折号堆砌：“限定联名饮品 ——”“限量联名周边 ——”“打卡赢福利 ——”，连着三个破折号，AI 文案的高频特征。
  2. 固定句式：“不仅……更有……”“和雪王一起解锁”，都是套路化模板。
  3. 没有具体信息：“XXX品牌”“X月X日”“X元起”，全是占位符，等于没说。

文案看着完整，但联名品牌、日期和价格仍未确定，句式也比较套路。先补事实，再改表达，才能走向可用的版本。

02｜问题根源

两个根源

首稿常见又平淡，可能是 AI 沿用了惯常写法，也可能是你还没说清哪些结果不能用。

  1. AI 默认讨好你：它容易顺着你的要求，给出常见、稳妥的回答。没有明确侧重点时，结果就可能平淡、套路，缺少有依据的判断。
  2. 没给它“不好”的标准：没有好坏参照和完成标准，它就难以判断哪些表达该保留、哪些必须改。

从诊断到修改

带着刚才发现的问题，来看五种常用改法。先选最影响使用的一项。

第二部分｜改到能用

03｜按问题挑方法

五个方法各补一个缺口

按问题选方法

首稿平庸，先别急着修。看清是哪个问题，再挑对应的方法。

方法 解决什么
生成多个方案 方向不对，这一份怎么修都修不好
加约束 方向对了，写法 AI 味重
做渐进迭代 长任务，等了好久，结果不符合预期
提中立问题 答案带了倾向
让它挑刺 表面没毛病，就是不够锐

五个里面，需要哪个用哪个，不用每次都凑齐。

生成多个方案

方向不对的时候

别在这一份身上继续修：让它出多份不同风格的方案，从中挑方向。

方向偏了，继续润色往往只会把原稿写得更顺。先让 AI 给几份不同风格的方案，比较侧重点，再挑值得展开的方向。

加约束

写法 AI 味重、又长又空的时候

约束是提前划给 AI 的线：不许说什么、多少字、什么形式。

“少一点 AI 味”太模糊。把问题落到具体写法：套话重复、篇幅过长，还是没有事实？约束要针对这些问题逐项写，AI 才有修改依据。

四类约束

  1. 禁用清单：把不许用的词一条条列出来：破折号、“不仅……更是……”、“总而言之”“值得注意的是”。
  2. 形式约束：定总字数和输出形式，列表还是表格，一次说清。
  3. 好坏参照：贴一个好例和一个坏例，指出希望它学哪里：说话的口气，还是每句话里装多少内容。
  4. 正向表述：把“不要”补成“应该做什么、做到什么程度”：“不要编数字”改成“只使用我提供的数字，没有的写‘待补’”，“不要太啰嗦”改成“每段最多三句”。

四类约束最后都写进提示词里：“禁止：破折号、‘总而言之’这类水话。格式：300字以内，用表格输出。”把“别太 AI 味”变成能一条条对照的规矩，AI 才有具体的修改依据。

参考：吴恩达《AI Prompting for Everyone》笔记、关于提示词工程的100个问题。

做渐进迭代

整篇模板文的时候

长任务先定大纲，再展开正文。结构还没确定时纠偏，通常比全文写完后重改省事。

直接要全文，容易得到“背景、现状、挑战、展望”这样的通用结构。先看大纲能否服务本次任务；重心不对，就在这一轮调整，避免正文写完才大幅返工。

三轮，每轮只改一小点

  1. 第1轮｜出三份大纲：“请给3份不同侧重的大纲：A 供应链 / B 营销 / C 门店运营。”看大纲就知道每个方向的重心，挑一个。
  2. 第2轮｜选方向细化：“选 B 方向，细化到三级标题，并标注每部分需要什么数据、什么案例。”结构不对，现在改只要一句话。
  3. 第3轮｜逐章展开：“按细化后的大纲写第2章完整内容，每个论点要有真实案例。”

大纲先定准，后面的修改就能集中在内容和表达上。

提中立问题

要客观分析的时候

要客观分析，就用中性表达，别暗示结论。

问句带着倾向时，模型可能顺着这个方向回答，漏掉另一面的理由。

问“大厂的活儿干够了，跳槽去创业公司值不值？”，可能只得到“成长快、能学得多”这一面的回答。换成“请列出从大厂跳槽到创业公司的利弊，覆盖薪资、加班强度、成长空间，不要偏向任何一方。”，再检查利弊是否都覆盖，最后由你决定。

检查问句是否暗示了答案。“X 是不是更好？”容易把讨论带向 X；改成“研究对 X 和 Y 的对比有何看法？”，更便于展开双方证据。

参考：吴恩达《AI Prompting for Everyone》笔记。

让它挑刺

表面没毛病，但不够锐的时候

别告诉它“改好点”，让它站在读的人立场挑刺，追问就是修改清单。

“再改好一点”没有指出改哪里。让 AI 站到读者的位置，先提追问，就更容易暴露数据缺口和逻辑跳跃，再据此修改。

做法，直接把这句话发给它：“假设你是我的老板，看完上面这份门店经营周报，1. 提出三个最尖锐的追问，专挑数据缺口和逻辑跳跃。2. 告诉我你希望下一版里看到哪些内容。只提问和点题，不要替我回答。”

它可能追问：“利润涨了三成，只看了线上渠道，线下门店的数据呢？”或指出对标资料过旧。核实这些问题、补足资料，再让它重写，下一轮就有具体方向。

04｜开新对话

越聊越笨

多轮之后质量变差，先检查对话里是否混入了太多旧资料和无关信息。

会话就是当前对话窗口。轮次增加后，旧要求、废弃方案和闲谈都可能留在上下文里；关键内容夹在中间，也可能被忽略。先检查哪些信息仍与当前任务有关。

一个案例

一位设计师抱怨 AI 绘画越用越差，对着提示词折腾了几个星期，回头一看：过去一个月，他把三十多张不同项目的参考图全丢进了同一个会话。

风格各异的参考图混在一起，结果也混入了不同项目的特征。这个案例中，改用新窗口后，画面恢复了预期方向。

实测数字

两组独立研究，测出了同一件事。

  1. 斯坦福长上下文实测：信息放在开头或结尾时准确率最高，埋在中段时下降超过三成。连专门标榜长上下文的模型也一样。
  2. 18个主流模型实测：有的模型输入到五六百词就开始衰减；上下文里塞进一个无关干扰项，质量就有可测的下降，塞到四个，质量成倍跌。

Anthropic 官方把这两组结论编成一句原则：上下文是一种有限的资源，塞得越多，新塞的每一条就越不值钱。

一百万 token 的窗口装得下海量内容，真正重要的是把窗口留给和当前任务相关的信息，越干净越好用。

先分清哪种笨

同样越聊越笨，原因可能是两类，处理办法完全不同。

  1. 抖动型：同样问题每次答案略不同，可能来自生成的随机性。先固定输出格式，检查变化是否影响使用，通常不用急着开新窗。
  2. 窗口问题：开始引用已废弃的旧方案，或忽略前面的要求，可能是上下文干扰。整理有效结论，再开新窗继续。

信号有三个，任出现一个就开新窗。

  • 任务主题变了：从写方案切到查数据，旧上下文全是负担。
  • 素材来源换了：上一个客户的资料还在窗口里，下一个客户的判断会被污染。
  • 聊得太久了：会话拉了很多轮，质量明显下滑，早期的规矩已经被埋了。

让窗口保持干净

规矩别被埋

规矩会失位，要把它带回“现在”。

早期要求在长会话中可能被忽略。要让它重新关注当前约束，可以用下面两招：

  1. 写进常驻位：把长期适用的约束放进“自定义指令”“风格偏好”或系统提示等位置，减少重复交代。结果仍要对照这些要求检查。
  2. 中途捞回来：长会话中途重申：“继续遵守：不许编数字、输出保持表格。”也可让它开工前复述关键约束，确认它理解了当前要求。

迁移包

开新窗口，只带结论，不带过程。

开新窗前，先把任务目标、已确认的决定和关键要求整理好，新对话就能接着做。

本任务目标：【一句话】
已确认的决定：【列点】
必须遵守的规矩：【从旧会话抄过来】
请基于以上继续：【当前要做的事】

已经否定的方案和无关讨论留在旧窗口；新窗口只带继续工作需要的信息。

两个日常习惯

日常把有效结论存下来，减少无关历史对下一次任务的干扰。

  • 按项目开窗：同一个项目的讨论共享一个窗口，跨项目绝不混。
  • 按天清理：收工时把结论写进笔记，第二天开新窗带结论开工。

分析长文档时，先让 AI 找出与问题相关的段落，再据此分析。这样重点更明确，也便于你回原文核对。

第三部分｜组合与速查

05｜每轮推进一步

首稿拿来当底子，方法放进逐轮修改的过程里，一轮干一件事，改动看得见。

首稿可能同时有方向、结构和表达问题。把所有要求挤进一轮，容易顾此失彼。先改最影响使用的部分，再处理下一项，每轮都检查是否有所改善：

  1. 第1轮｜定方向（提中立问题、生成多个方案）：“不要偏向任何一方。先给几份不同侧重的大纲。”→ 看大纲，挑方向。
  2. 第2轮｜定结构（做渐进迭代）：“按挑中的方向细化到三级标题。”→ 结构定下来了。
  3. 第3轮｜压AI味（加约束）：“按大纲逐章展开。禁止：破折号、‘不仅……更是……’、‘让我们一起’。”→ AI 味被压住，正文落地。

上面三轮是长文分析类任务的常见节奏。问题多的时候，哪个问题要紧就先做哪个，后面的轮次接着清；改到位了就停，不用跑满三轮。

06｜按场景查句式

要写东西的时候

下面九个场景先从创作和整理开始。找到相应句式，换上自己的任务、资料和要求。

写文案 / 起草内容

你是[角色]。请为[对象]写[内容类型]。
要求：[格式 / 字数 / 语气]
禁止使用：[AI 特征列表]
参考风格：好例「……」、坏例「……」

做创意 / 头脑风暴

请为[主题]提供[数量]个[创意类型]，风格分别覆盖：
A)[风格1] B)[风格2] C)[风格3]
每个创意必须包含[具体元素]。

写长文 / 报告

分步执行，不要一次写完：
① 拟定[数量]份不同侧重的大纲
② 选方向，细化到三级标题
③ 按大纲逐章扩展，案例支撑

改写 / 翻译 / 润色

请将以下内容改写为[目标风格]。
保持原意不变，只调整[语气 / 措辞 / 篇幅]。
参考样本：[一段目标风格的示例文本]

提取信息 / 整理数据

请从以下内容中提取[字段A]、[字段B]、[字段C]。
用[表格 / 分点列表]输出。
找不到的标注[未找到]，不要编造。

要判断东西的时候

需要分析、选择或评估时，再用下面四组句式。重点是明确维度和标准，避免提前暗示结论。

做分析 / 做对比

请客观分析[主题]，从[维度A]、[维度B]、[维度C]三个角度展开。
不要偏向任何一方。
用[表格 / 分点]输出。

做调研 / 做研究

请研究[主题]，时间范围[起止]。
仅使用[权威来源类型]的数据和报告。
请非常深入地分析。

做决策 / 选方案

我面临[决策场景]。请列出[数量]个可选方案。
每个方案给出：最佳情况、最差情况、最可能结果。
先让“乐观派”和“怀疑派”各陈述最强三点，再互相反驳一轮，最后综合给推荐。
被反驳掉的观点不要复活。不要偏向任何方案，由我做最终决定。

审查 / 评估 / 打分

请从[维度A]、[维度B]、[维度C]评估以下内容。
每个维度先给出评分(0-10)和具体理由，最后再汇总总分。
评分标准：[每个维度的具体标准]

小结

  1. 首稿平庸有原因：AI 默认给“最安全、最常见”的答案，你还没给它“不好”的标准。看清原因，修改才有方向。
  2. 按问题挑方法，逐轮改：方向不对就让它出多份不同风格的方案；AI 味重、又长又空就加约束；模板文就先出大纲再展开；要客观就用中性表达；不够锐就让它挑刺。
  3. 让窗口保持干净：任务变了、素材换了，或长会话质量下滑时，考虑开新窗，带上目标、有效结论和关键要求。

挑一份还不能用的首稿，先找最影响使用的问题，选一种方法改一轮，再比较前后差别。
