AI文字创作

AI自媒体的第一课：把积累变成作品

定位 · 流程 · Skill

第一部分｜先把账号定位说清楚

01｜明确创作起点

AI创作，从一个模糊想法开始。

贯穿示例（自拟情境）

一位参与过企业AI培训和工作流程优化的实践者，想做一个分享AI经验的新媒体账号。他有工作经历和零散案例，还没想清楚应该写给老板、管理者、普通员工还是AI爱好者。

创作者最初只说了一句话

我想做一个分享AI工作方法的账号，希望内容实用，也能让别人记住我。

这句话由创作者提供。AI先识别其中缺少的目标读者、具体问题、价值承诺、表达身份和素材边界，不直接生成选题或正文。

02｜完成定位访谈

让AI追问关键空白

创作者先说清经历、读者和素材，AI才有判断账号方向的依据。

给AI的实际输入

我参与过企业AI培训和工作流程优化，想做一个分享AI工作方法的账号，目前还没确定最想服务哪类人。请先通过访谈帮我梳理定位，每轮最多问3个问题。只提问，暂时不要给出定位结论。

AI需要问清的四组问题

  1. 创作者有什么：做过哪些事，解决过哪些问题，手里有哪些真实作品和案例。
  2. 潜在读者是谁：哪些人曾向他提问，这些人在什么工作场景里遇到麻烦。
  3. 读者要改变什么：他们希望看懂什么、完成什么，或避免哪些返工和错误。
  4. 内容能否持续：哪些经验能够长期积累，哪些话题缺少素材或超出创作者的能力边界。

完成访谈的标志：目标读者、核心问题、可持续素材和能力边界已经说清楚。

由创作者做出定位选择

AI负责把候选方向和代价摆到桌面上，创作者决定自己愿意长期站在哪里。

AI整理的三个候选方向

候选方向 优势 代价
企业老板的AI决策 商业话题集中，容易和管理决策衔接 需要更多成本、回报和组织变革材料，现有积累不足
普通职场人的AI效率 受众广，手上的操作素材容易改写 竞争范围宽，个人特点难以突出
中小企业管理者的AI落地 和已有项目经验、团队问题与素材高度重合 受众更聚焦，每篇都要回应管理场景

创作者的决定

选择“中小企业管理者的AI落地”。这个方向与现有经验和素材的重合度最高，也能稳定回应一类人的重复问题。

能长期写下去的方向，要让读者的问题与手里的积累真正相遇。

03｜生成定位卡

AI把访谈回答和方向选择整理成定位卡，创作者确认每一项。

示例输出｜账号定位卡

定位项 已确认内容
目标读者 想在团队内落地AI，又缺少技术背景的中小企业管理者
核心主题 任务怎样交给AI，AI结果怎样审核，个人技巧怎样变成团队方法
价值承诺 帮读者把模糊的AI想法变成一项可以开始试做、检查和复盘的工作
表达身份 一名实际参与企业AI培训和流程优化的实践者，用同行分享经验的口吻说话
内容边界 不预测投资机会，不发布无法复核的效率数据，不把个别案例扩大为通用结论
信任来源 项目记录、任务说明的修改前后对比、工具试用记录、培训材料和公开可查的来源

创作者的确认

把任意一个新话题放进来，应该能快速判断“适合写、需要改角度、不进入账号”。判断依据来自目标读者、核心主题、现有素材和内容边界，不使用“我感觉这个会火”代替选择。

第二部分｜把一个选题写成作品

04｜建立内容栏目

栏目要同时对应读者的重复问题和创作者的持续素材。

创作者提供定位卡，AI把读者问题与已有素材分类，生成四个长期栏目。

示例输出｜四个内容栏目

栏目 回应的读者问题 可持续使用的素材
AI任务拆解 一项工作怎样交给AI 任务说明、提示词和修改记录
返工现场 AI输出为什么不能直接用 失败案例、审核问题和前后对比
工具选择 面对很多产品该怎样选 官方资料、同题试用和适用条件
团队落地 个人技巧怎样变成团队方法 培训提纲、工作流程、模板和复盘

05｜设计内容

为选题确定标题

三选一

围绕选题“AI任务开始前需要说明哪些信息”，AI生成三个标题，创作者从中选择。

示例输出｜三个候选标题

标题角度 候选标题
读者问题 为什么只说任务名称，AI容易写偏
核心判断 AI开始工作前，需要知道哪4件事
读者行动 把工作交给AI前，先写清这4件事

搭出正文框架

AI根据标题和材料生成提纲，创作者调整重点和顺序。

示例输出｜文章提纲

文章部分 当前任务 使用的材料
开头 呈现“帮我写周报”带来的返工 自拟工作场景
原因 解释任务名称为什么不足以指导AI工作 修改前的任务说明
方法 说明目标、背景、材料和交付标准各自解决什么问题 四项任务说明模板
示范 把同一项周报任务重新写一次 修改前后对比
收尾 引导读者重写手里的一份任务 四项任务说明模板

06｜写出初稿

AI按照已确认的提纲写作，创作者检查内容是否写偏。

给AI的写作指令

请依据选题、标题、提纲和已有素材写出完整初稿。保留五部分顺序，不改动核心判断。没有材料支撑的内容标记“待补材料”，不补写事实、案例、数字或引语。

07｜固定文风

建立首版风格卡

风格卡把创作者反复出现的表达选择写成明确规则。

贯穿示例的偏好输入

创作者希望自己像一位做过同类项目的同行，用工作现场和前后对比说明方法，段落短，判断直接。他不喜欢业务黑话、大而空的承诺和无法复核的效率数据。

示例输出｜首版风格卡

风格项 明确规则
说话关系 像做过同类项目的同行分享经验，直接，不端着
句段节奏 段落短，关键判断单独成句，操作步骤按顺序写
举例习惯 优先使用工作现场、任务说明前后对比和可填写模板
禁用表达 不堆业务黑话，不虚构效率数据，不把个人经验扩大为通用结论

规则要有出处。已经有稳定作品时，就从三到五篇本人满意的文章里提炼。要是作品还不够，就先采用本人说出来的偏好。

保持观点，改变平台表达

一稿多发要保住同一个问题、判断和行动，各平台只重新组织阅读节奏。

共同输入

已经确认的初稿和风格卡。三种平台稿都保留同一个读者问题、核心判断、事实材料和读者行动。

换平台可以改节奏，核心判断和事实仍是同一份。 示例输出｜三种平台的表达选择

平台 标题与开头 主体 结尾
公众号长文 保留方法型标题，从“帮我写周报”的返工场景进入 完整解释四项信息怎样影响结果，附前后对比 引导读者用模板重写一项手头工作
小红书图文 把标题改成可扫读的四项清单，开头直接点出返工问题 把四项信息拆成图文要点，保留一组前后对比 引导读者收藏模板并检查一项任务
短视频口播 把标题改成口语化提问，用两句对话重现返工现场 用口语讲四项信息，画面同步展示任务说明被逐步补全 引导观众暂停画面，照着模板重写一遍

08｜审校发布

AI负责把问题找全，创作者负责决定哪些必须修改才能发布。

AI同时读取待审稿件、账号定位卡、选题、提纲、风格卡、原始素材和发布平台要求，分四轮检查：

  1. 事实：人名、数字、时间、引语、产品功能和结论能否在原始素材中找到。
  2. 逻辑：每个分论是否支撑核心判断，事实、推断和作者判断是否混在一起。
  3. 定位与文风：文章是否回应目标读者的问题，口吻、节奏、举例和禁用表达是否符合风格卡。
  4. 平台与行动：篇幅、格式和互动是否匹配平台，结尾是否只推动一个主要行动。

AI的产出

一份按照“原文位置｜问题类型｜问题原因｜修改建议”整理的审校清单。

创作者的决定

逐条决定删除、补材料、补解释或重写。

第三部分｜用Skill建立创作系统

09｜使用现成Skill

按任务选择现成Skill

先看当前要完成什么，再选择只解决这项任务的Skill。

现成Skill 适合的任务 从SKILL.md提取的核心特点
wewrite（作者：imraywang） 完成公众号从选题到发布的全流程 默认完成选题写作和审稿，配图排版和发布按需追加
baoyu-format-markdown（作者：JimLiu） 整理文章结构 只调整结构和格式并保留作者原话
Viral Writer（作者：nashsu） 把一个主题写成多平台内容 写作前从11个内容维度完成构思并同时生成标题和配图提示词
khazix-writer（作者：KKKKhazix） 撰写AI题材科技公众号长文 活人感写作：用亲历和口语节奏分享AI体验与真实判断
ljg-writes（作者：lijigang） 把商业观点写成逻辑递进的中文长文 观点文章风格：用案例解释核心判断再用新场景和反例检验边界
qiaomu-syc（作者：joeseesun） 撰写都市人物和情感故事 用细节写情绪：不直接说出感受让动作和物件传递情绪

给现成Skill明确的任务

调用现成Skill时，只需要说清任务、材料和交付边界。

提供真正决定结果的输入

把定位卡、选题或文章卡、已有素材、发布平台和必须遵守的边界交给Skill。

说清当前一步的交付物

选题阶段要选题表，结构阶段要提纲，文风阶段要风格问题清单或修改稿。先只推进当前一步，中间选择才有机会由人确认。

保留Skill本身的流程

无需在调用语中重复抄写复杂方法。当Skill先提问、要求补素材或给出中间结果时，按它的流程完成必要交互。

最短可用调用示例

使用[Skill 名称]。我要做的是[具体任务]，对象是[账号、产品或题材]。
现有材料包括[材料清单或文件]。请按 Skill 的流程检查输入，需要我作决定的时候停一下。
这一步先给我[要的成果]，每一项标明依据的材料，以及还缺什么。

10｜创建个人Skill

为什么需要个人Skill

个人Skill，把你反复验证过的经验留给下一次创作。

必要性 个人Skill沉淀什么
资产不再散落 保存定位卡、内容栏目、风格卡、代表作品和审校标准
流程不再重讲 固定从读取材料到生成、确认和审校的顺序
修改能够积累 把反复出现的人工修改转成新的写作规则
关键选择仍由人做 明确哪些节点必须等待创作者确认

把反复验证的修改留下来，下一次创作就多了一条可靠的规则。

用提示词创建个人Skill

把已有资产、固定流程和交付标准一起交给AI。

创建指令示例

请把我的账号定位卡、内容栏目、风格卡、代表作品、修改记录和发布前审校清单，整理成一个个人创作 Skill。写清这四件事：
1. 触发条件：什么任务下调用它，需要读取哪些资料。
2. 固定流程：按什么顺序工作，每一步交出什么，哪些节点必须由我确认。
3. 完成标准：写成可以检查的条件，比如一篇只有一个核心判断，关键事实有出处，文风符合样例，平台格式正确，结尾只推动一个主要行动。
4. 学习机制：以后我每次改稿，对照修改前后的文字，提出应该增加、删除或改写的规则，经我确认后再更新。
资料中没有写明的偏好标记“待确认”，不要自行补充。
先交出 Skill 目录和 SKILL.md 草案，不修改原始资料。

小结

  1. 定位从访谈开始：创作者先交出真实经历和模糊想法，AI补齐关键问题，创作者从候选方向中做出取舍，最终形成定位卡。
  2. 作品从选题展开：定位卡生成内容栏目，选定题目后确定标题与提纲，AI仅使用已确认材料写出初稿。
  3. 发布要保持辨识度和信任：风格卡统一说话方式，平台改写只调整表达节奏，审校稿关闭事实、逻辑、定位和平台问题。
  4. 系统来自持续积累：现成Skill解决当前环节的专门问题，个人Skill把已验证的方向、写作、风格和质量标准留给下一次创作。
