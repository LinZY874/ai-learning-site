WorkBuddy 保姆级入门教程

从安装开始，让 WorkBuddy 越用越顺手。

第一部分｜装好 WorkBuddy

01｜AI 办公工作台

能交付什么

WorkBuddy 把办公任务做成可以直接拿走的文件。

常见交付有：

  • 一份资料可以整理成 Word 或 Markdown 文档。
  • 一组数据可以整理成 Excel 表格和分析报告。
  • 一个汇报需求可以生成 PPT。
  • 一个混乱的文件夹可以按要求重新整理。

例如，把装有三张门店销售表的文件夹交给 WorkBuddy，最后拿回一份分析报告和一份汇报 PPT。

参考：WorkBuddy 简介、快速开始、模块五_课2_WorkBuddy入门（第4页）。

WorkBuddy 怎么干活

把完整任务交给 WorkBuddy，不用替它安排每一步。

  1. 交代任务：说清最终要完成什么，并指定 WorkBuddy 可以使用的资料。
  2. 执行任务：WorkBuddy 拆分步骤、选择工具，完成操作并生成产物。
  3. 决定收尾：人工验收产物；符合要求就归档，不符合要求就带着修改意见返工。

02｜安装与登录

下载客户端

从 WorkBuddy 官网下载与当前电脑匹配的版本。

打开 WorkBuddy 官网，点击下载入口，选择 Windows 或 macOS 版本。

打开安装包

下载完成后，打开安装包进入安装向导。

在浏览器的下载记录或系统下载文件夹中找到安装包，双击运行。下图以 Windows 为例；macOS 用户打开对应安装文件后，按系统提示继续。

选择安装用户

个人电脑选择“仅为我安装”，可以减少对其他账号的影响。

安装向导会询问哪些电脑用户可以使用 WorkBuddy。个人电脑建议选择“仅为我安装”；多人共用的电脑，再根据实际需要决定是否为所有用户安装。

选择安装位置

确认安装位置后，点击“安装”开始写入程序文件。

没有明确的磁盘管理要求时，可以保留默认位置。需要改位置时，选择空间充足且长期保留的文件夹，再点击“安装”。

完成安装

看到安装完成页面后，点击“完成”打开 WorkBuddy。

勾选“运行 WorkBuddy”后点击“完成”，客户端会直接启动。暂时不想打开，也可以取消勾选，之后从桌面或应用列表启动。

微信扫码登录

在客户端点击登录，再到浏览器里完成微信扫码。

点击客户端中的登录按钮后，系统会打开浏览器登录页。使用微信扫描页面上的二维码，并在手机上确认登录。

选择账号类型

个人使用选择个人登录，企业账号选择企业登录。

扫码后按账号用途选择登录方式。个人用户选择个人登录；已经加入企业版并准备使用企业空间时，选择企业登录。

参考：开启你的第一个任务。

第二部分｜跑通一个任务

03｜三个区域

主界面分成左、中、右三区，先认清每块放什么。

区域 这里放什么
左侧边栏 新建入口、任务列表、搜索与账号入口
中间对话区 消息记录、文件附件和输入框
右侧结果区 产物、工作空间文件、文件变更和网页预览

参考：快速开始、任务管理、任务对话。

04｜工作空间

工作空间可以为任务指定工作目录。

  1. 点击输入框左下角的 选择工作空间，选择当前任务要使用的目录
  2. 选择完成后，WorkBuddy 会基于该目录读取和处理文件
  3. 也可以直接开始任务，WorkBuddy 会在默认目录中生成结果

参考：创建任务、默认权限与安全沙箱。

05｜权限边界

日常保持默认权限，让高风险动作停下来等你确认。

权限模式 怎样工作 适合什么情况
默认权限 常规任务继续执行，越过工作空间、删除重要文件、运行脚本或访问敏感能力时请求确认 日常文档、表格、资料整理和第一次处理的新任务
完全访问权限 减少确认步骤，可以直接执行更多文件、命令和联网操作 隔离、可信、可恢复的临时环境

完全访问权限会对当前客户端里的所有任务生效。处理客户资料、财务资料、唯一文件或批量删除任务时，最好保持默认权限，并先看清操作类型、目标路径和影响范围。

参考：默认权限与安全沙箱。

06｜工作模式

按你要的是答案、计划还是成品，选择合适的工作模式。

模式 会怎样做 适合什么情况
仅问答 Ask 回答问题、解释资料，不修改文件 先摸清资料、确认概念或讨论思路
计划 Plan 先补齐信息并给出计划，等你确认后再执行 步骤多、方向还没定、改动范围较大的任务
默认 Agent 理解要求后直接执行并交付结果 目标明确的日常文档、表格和文件处理

日常小任务可以直接用默认模式。任务做错方向会浪费很多时间时，先开计划模式，把步骤和范围谈清楚再执行。

同样面对一项工作，问答给解释，计划先画路线，执行交出成品。

参考：新建任务栏。

07｜模型选择

拿不准时先用均衡模式，任务特别简单或特别复杂再换档。

模型模式 适合什么任务 主要取舍
快速模式 日常问答、格式转换、小段文字修改 响应快，消耗低
均衡模式 写文档、分析数据、多文件处理 兼顾效果和速度
极致模式 多步骤推理、复杂分析、需要反复验证的任务 用时更长，消耗更高

零基础使用时先用均衡模式。只有当速度、复杂度或消耗已经成为明确问题，再换成另外两档。

参考：模型配置。

08｜发出任务

把任务说完整，WorkBuddy 才有可能一次做对。

四项说清楚

  1. 目标：最终要完成什么。
  2. 材料：使用哪个文件夹、文件或截图。
  3. 交付：最后要得到什么文件，放在哪里。
  4. 限制：时间范围、字数、风格、不能改动的内容。

示例

分析“8月销售分析”文件夹里的三张门店销售表，找出销售额和毛利变化最大的品类。生成一份不超过10页的汇报PPT，关键结论注明对应表格和字段，保存回当前工作空间。原始销售表不要修改。

需要补充资料时，可以拖入文件、粘贴截图，或用 @ 引用工作空间里的文件。

只报任务名像只说“出发”，目标和材料说清楚，工作才有方向。 参考：创建任务、新建任务栏。

09｜跟进执行

同一项工作留在原对话里继续推进。

执行中可以做什么

  • 查看它正在分析什么、生成什么，以及已经完成哪些步骤。
  • 发现资料缺失时，继续上传文件或补充说明。
  • 发现方向偏了时，立即提出具体修改，也可以先停止执行再重做。
  • 同时创建其他任务，让多项工作并行推进，再从侧边栏切换查看。

修改意见要落到对象上

把汇报里的第二张图改成按月份比较的折线图，保留原始数据表，结论部分补充毛利下降最大的两个品类。

继续处理同一项工作时留在原任务里，WorkBuddy 会沿用已有对话和资料。工作目标已经完全改变时，新建任务更清楚。

参考：任务对话、任务管理。

10｜验收结果

把 WorkBuddy 交出的文件当作待验收的成果。

右侧结果区提供四种检查入口

  1. 产物：打开生成的 PPT、PDF、文档或表格，检查最终交付。
  2. 工作空间文件：确认文件是否写进正确目录，相关文件是否齐全。
  3. 变更：查看 WorkBuddy 修改了哪些文件，具体内容改了什么。
  4. 浏览器：预览网页、页面原型或可以直接打开的结果。

验收时重点看三件事

  • 结果有没有回答原任务。
  • 文件名、格式和保存位置是否正确。
  • 原文件与无关文件有没有被误改。

参考：结果查看、右侧边栏。

第三部分｜用好长期记忆

11｜记忆怎样工作

WorkBuddy 会从会话里整理有长期价值的信息，在相关任务里作为背景参考。

  1. 整理会话：系统每晚读取当天的会话历史。
  2. 形成记忆：从中提取事实、偏好、人物关系和近期跟进事项，整理成记忆数据。
  3. 匹配任务：收到新请求时，查找与当前任务相关的记忆。
  4. 带入背景：把匹配到的记忆放进当前任务，帮助 WorkBuddy 理解你的要求。

没有关系的记忆不会全部塞进每一次对话。记忆在这里负责提供背景，不代替当前任务里的具体材料和要求。

记忆带来相关背景，这一次的任务仍要带上自己的材料。 参考：记忆。

12｜写入记忆

要它长期记住什么，就直接说清内容和适用范围。

适合写进记忆的内容

  • 稳定背景：我经营三家烘焙门店，日常汇报主要看销售额、毛利和复购。
  • 长期偏好：以后写经营汇报，先给结论，再放数据和行动建议。
  • 固定口径：提到“老客”时，指过去90天内购买过两次以上的客户。
  • 持续事项：未来一个月持续跟进秋季会员活动，相关任务沿用同一套活动背景。

说法示例

请记住：以后为我整理经营周报时，开头先用三句话写清结果、问题和下一步，正文再放数据依据。这个要求适用于所有门店周报。

范围写得越清楚，记忆越不容易被用到无关任务里。只影响眼前这一次的临时要求，直接放在当前任务里即可。

参考：记忆。

13｜管理记忆

把记忆当作需要定期维护的个人资料。

点击左侧边栏底部头像，进入“设置”，打开“记忆”：

  1. 查看：阅读系统整理出的记忆摘要，确认它记住了什么。
  2. 改正：用对话告诉 WorkBuddy 哪一条发生了变化，以及新的说法是什么。
  3. 删除：清除过期、错误或不希望继续使用的记忆。
  4. 关闭：不希望系统继续从新会话中整理记忆时，可以一键关闭。

示例

忘记“每份汇报控制在5页以内”这条偏好。以后只有月度经营会使用5页限制，其他汇报按内容决定页数。

参考：系统设置、记忆。

14｜导入记忆

换到 WorkBuddy，也能把在其他 AI 里形成的使用习惯带过来。

在“记忆”页面中选择“导入”：

  1. 复制页面提供的提示词，发送给你过去常用的 AI 产品。
  2. 让原来的 AI 整理它已经了解的背景、偏好和习惯。
  3. 把整理结果粘贴回 WorkBuddy，检查内容后添加到记忆。
  4. 删除过期信息，补充适用范围，再开始新的任务。

导入的重点是保留稳定的工作背景和表达偏好，不必搬运全部聊天记录。整理后的摘要更容易检查，也更容易在新任务里正确使用。

参考：记忆。

小结

  1. WorkBuddy 负责交付：把整件工作说明白，它会读取资料、规划步骤、执行并生成文件。
  2. 工作空间负责边界：一项任务一个文件夹，日常保持默认权限，重要动作由人确认。
  3. 对话与结果区负责协作：在对话里跟进和修改，在结果区查看产物、文件与变更。
  4. 记忆负责长期配合：把稳定背景和偏好交给记忆，定期检查、改正和清理。

WorkBuddy 的价值，会在一次次真实任务中慢慢显现。
