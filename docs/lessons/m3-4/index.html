AI生图：文章配图

我用两个生成器，把配图做成了一条产线

第一部分｜两类配图

01｜配图的分工

给同一篇文章配图，可以突出固定角色，也可以把重点放在内容路径上。

带 IP 信息图。沿用前两课做好的固定角色，让它出现在海报和信息图里。读者反复看到同一个 IP，会更容易把这个角色与你的内容联系起来，适合需要建立个人辨识度的场合。

无 IP 通用配图。用一组白色 3D 信息图围绕事情本身展开，不绑定固定角色；需要表现读者动作时，可以用通用人物。它更适合把方法与流程讲清楚。

02｜稳定出图三步

想让整篇配图连成一套，先定规则，再逐张生成和检查。

  1. 先立规则。带 IP 用“角色闸门”固定身份，无 IP 用“门禁清单”检查内容是否适合出图。这些名字都指一组必须遵守的要求，先写清楚，后续图片才有共同依据。
  2. 喂文章逐张出图。把文章交给生成器，每张对应一个信息点，一次先生成一张，便于及时发现和修正问题。
  3. 逐张自检。每一张都拿规则对一遍，不合格的直接重出，不带着问题往下走。

这三步走顺后，换一篇文章也可以沿用同一套流程。

第二部分｜带 IP 信息图

01｜IP 是内容资产

读者记住的不只是文章，还有那个反复出现的角色。

同一篇文章配上固定 IP，读者看到的不只是内容，还有那个反复出现的角色。下一次再见到它，就多了一条认出你的线索。前提是每张图都保住角色特征，同时服务文章信息。

IP 稳定下来，每次配图都在积累同一份视觉记忆。

02｜操作示例

先准备文章与生成器，再逐张确认信息和图片。

把文章文件和小A 信息图生成器（xiao-a-comic-infographic）一起交给 AI，先让它提炼信息点。你确认没有曲解原文，再用 GPT Image 2 逐张生成中文配图；检查通过后继续，最后插回文章对应段落。

真机操作：带 IP 配图提示词

要换成自己的 IP，把角色闸门中的身份描述替换为自己的设定，并提供正面、侧面、背面三视图。文章和出图流程可以沿用。

03｜skill 功能说明

配图四步流程

生成器收到文章后，按下面四步把内容变成配图。

  1. IP 调用。把角色身份、表情动作、信息图版式一起调进来。
  2. 文章压缩。提炼标题与 3 到 5 个信息点，再安排画面结构，以及 IP 的站位和动作。
  3. 生成提示词并出图。把压缩结果写成提示词，逐张出图。
  4. 质检。三看：身份没漂（每张图里还是同一个角色）、文字够短、一眼读懂。

这四步由生成器执行，你不必逐项手动编排。先重点核对提炼的信息点是否准确，出图后再检查角色和文字，避免让错误一路带进成品。

锁死角色

用一份固定的身份描述，让每次出图都参照同一个角色。

角色闸门（IP_DNA）就是角色的固定身份描述。每次出图都原样带进提示词，生成后也用它检查造型有没有漂移。

以小A 为例，这段描述写清这些细节：

白色圆角屏盒、深蓝竖胶囊眼、右下蓝蓝橙三按钮、底部蓝包边、短粗蓝腿。默认没有手臂，需要指向或者递交东西的时候才伸出来。

把辨识细节写清楚，就能减少每次出图的随意变化。换成自己的 IP 时，整体替换这段描述，继续沿用同样的结构和写法。

选情绪和版式

表情动作决定角色怎么演，信息图结构决定内容怎么摆。

表情库和动作库。库里有 15 个表情标签，如 gentle-smile（温和微笑）、puzzled-question（疑惑提问），以及挥手、递便签、举高、后仰支撑四个动作参考。按内容选合适的情绪和姿态，不必逐张照搬。

信息图结构。skill 备了五类版式：流程用 3 到 5 步，对比用左右分区，清单用编号卡片，概念从中心展开，观点总结用大标题加三个证据点。先看信息之间是什么关系，再挑版式，让小A 在旁边引导阅读。

04｜成品展示

《AI 教不来的 4 种能力》的封面配图，同一套内容出了两个版本。

信息卡片版式：四个能力各占一张卡片，配 3D 图标，小A 站在卡片前面，信息密度高，适合内容本身有明确分类的封面。

编号标题版式：小A 站在画面正中，四个能力用编号和引导线分列四周，主角感更强，读者第一眼记住的是角色。

成品：带 IP 封面的两种版式

两版都能用，看这篇文章更需要分类清楚，还是更需要强化角色印象。

第三部分｜无 IP 通用配图

01｜图集要顺着读

一组图集要有前后关系，让读者从第一张顺着读到最后一张。

无 IP 配图用白色 3D 信息图，一张讲一个动作，整篇选 5 到 8 个动作节点。把文中的方法串成一条路径，读者就更容易抓住“先做什么、再判断什么、最后拿到什么”。

检查时把图按顺序摆好：读者能否看出每一步怎样接到下一步？能连起来读，图集才真正讲清了这条路径。

02｜操作示例

这次换用通用配图生成器，先把整组图片的清单定下来。

把通用配图生成器（Knowledge Object Atlas）的提示词和文章文件一起交给 AI，先给出图集清单，再用 GPT Image 2 逐张生成中文配图。

真机操作：无 IP 图集提示词

换成自己的文章时，替换上传的文档即可。要换视觉风格，再修改提示词里的“风格骨架”，可以使用手绘、扁平、杂志或像素风。白色 3D 是默认风格，工作流、门禁与自检要求继续沿用。

03｜生成器功能说明

出图流程

文章交出去之后，生成器按五步走完。

  1. 先读文档。分开“用户旅程”和“系统机制”：前者是读者经历和做的事，后者是系统内部怎么运行。这组图画前者。
  2. 只选 5 到 8 个节点。挑的时候盯着用户：一开始遇到什么、第一次看到什么、怎么做出选择、在哪里反馈或判断、什么时候拿到结果、下一次为什么更准。
  3. 每个节点写一句判断，告诉读者在这一步要记住什么。
  4. 把判断翻译成物理信息模型，也就是用具体物件及其关系表达意思。选一个白色 3D 物件，或一组关系清楚的物件，避免拿随机图标凑画面。
  5. 先输出图集清单，再逐张出图。清单定下来，图才一张一张往下走。

出图门禁

先说明这一张要讲的动作和判断，再决定怎么画。

每张图先填 5 个字段：编号、用户动作、判断句、中心隐喻、是否可感知。最后一项要问：这是读者能实际经历的动作或认知变化吗？再用下面四条门禁检查。

  1. 动作能按顺序读。把六张图连起来，读者能跟着做完一条路径，避免变成一堆框组成的架构图。
  2. 判断句是给人看的一句话。写读者能记住、能用于判断的话，避免变成参数或功能说明。
  3. 隐喻能画成物理信息模型。中心隐喻回答“用什么物件或场景表达这句话”。它必须能变成看得见的 3D 物件与关系；无法具体画出来，就换一个隐喻。
  4. 每张图只讲一个动作。一张图塞进两件事，读者就抓不住重点。

四条都过，才进入生图。

单张结构

每张图固定三层，读者不用找就知道先看哪里。

Top 顶部：编号、英文 slug（英文短名）、中文步骤名，中文不超过 6 个字。

Center 中部：一个白色 3D 信息模型，中心画面要一眼看懂动作，最多带 3 个短标签。

Bottom 底部：一句中文判断，不超过 12 个字。它给的是认知结论，不是对画面的描述。

图集：01 先别慌

三层固定以后，六张图摆在一起自然成一套。

中央模型

中心物件怎样排列，要让读者看得出它们之间的关系。

需要多个物件时，先统一结构和方向，再用排列关系表达一个意思。下面六种组织方式可以按内容选用：

  1. 同类物件沿时间线生长，呈现逐步发生的变化
  2. 输入逐步变成输出，呈现处理前后的变化
  3. 层层堆叠，呈现逐层积累的关系
  4. 多个同质节点环绕核心，呈现它们与同一中心的关系
  5. 多个对象被筛成少数对象，呈现筛选与收敛的过程
  6. 一条路径从混乱走向清晰，呈现逐步理清的过程

如果一张图同时讲几个不相干的意思，变成随机图标拼贴，或把系统内部机制画成主角，就回到原来的用户动作重新组织画面。

04｜图集六张成品

再看这六张成品，检查它们怎样接成一条阅读路径。

《AI 教不来的 4 种能力》的图集，六张顺着读下来：

01 start-here 先别慌 / 先别被别人吓住

02 ask-better 问具体 / 问清楚才有好答案

03 verify 做判断 / 看着对不等于真

04 try-first 先动手 / 先试再谈方法

05 beginner 像新人 / 好奇心比经验更稳

06 carry-on 带着走 / 四种能力比工具更稳

图集：六张成品

六个节点依次从“先别慌”走到“带着走”，把读者的起点、尝试和最终收获连了起来。

小结

  1. 带 IP 信息图：用小A 生成器，让读者记住你。
  2. 无 IP 图集：用通用配图生成器，让读者读懂文章。选一篇自己的文章试做，先核对信息点，再检查每张图是否只讲一个动作、整组能否连起来读。
