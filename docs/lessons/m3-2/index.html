AI商业视觉

AI生图：IP 创建

从零做出属于你的角色资产，它自己就是招牌

第一部分｜先看结果

01｜角色设定

这节课，我们要做一个换了场合仍能认出来的角色。

做原创 IP，先给角色一张名片：叫什么、什么性格、适合做什么、哪些方向要避开。把这些说清楚，后面换装、换风格就有了判断依据。

我们以 AI 学习搭子「小A」为例，先看这张角色名片的五项内容：

  • 名字：小A。A 来自 AI，好记、亲和。
  • 一句话介绍：从课程系统里长出来的盒状小伙伴，AIGC 学习搭子。
  • 性格：安静可靠、好奇、爱帮忙、不抢戏。
  • 喜好：收集并点亮新 skill、整理资料、陪人踩坑。
  • 雷区：勿高冷卖弄、勿低幼过度可爱、勿强机械科技感。

小A 的软胶潮玩定稿

02｜形象资产

把一个角色做成可反复使用的形象，才是这一课的目标。

一张图解决一次出图需求；形象资产则把脸、颜色、比例和性格固定下来，让后续海报、周边、详情页都有共同参照。你留下的是一套能继续使用的角色资料，而不只是这一张好看的图。

角色名片之外，还要准备图片。下面四项做齐，后续使用才有依据：

  • 基准定稿图：确定下来的形象主图，后续所有生成都以它为唯一基准。
  • 三视图：把正面、侧面、背面画在一张图里，说明角色转过身是什么样。
  • 角色设定：名字、一句话介绍、性格、喜好与雷区，决定形象往哪个方向生长。
  • 延展图：至少做 3 张换装或换风格图，检查变化后还能不能认出同一角色。

第二部分｜做出 IP

03｜定调性

先说清角色要为谁服务，再一起把方向聊具体。

把品牌定位、用途、受众和想要的气质写进同一个对话，让 AI 提出角色方向。你挑出接近目标的部分，也说清哪里不合适；每一轮反馈，都让下一版有更明确的依据。

关键动作：一步步收敛

先给方向，再指出要保留和要修改的特征，不必一开始就想齐所有细节。

工具：WorkBuddy + DeepSeek

本例用它构思、起名和写设定。先发项目背景与已有想法，得到方案后，再具体说明喜欢和需要修改的地方。

04｜发散与收敛

先砍掉「一眼 AI」的方向

第一版容易落在常见形象上，先检查它是否符合你的定位。

第一版是常见的 AI 机器人：圆头、机械臂、蓝白金属。题材很清楚，但我们要的是亲和的学习搭子，这个方向还缺少自己的特点。

否掉它的三个理由：

  1. 太接近常见的 AI 机器人符号，缺少新意。
  2. 作为长期反复出现的角色，辨识度不足。
  3. 机械感一旦定下来，后续延展也会带着这份气质。

反例：刻板机器人

先发散，再收敛

让 AI 给出足够多的可能性，然后大胆做减法。

先发散，就是让 AI 提出不同方向供你比较；再收敛，就是保留符合定位的特征，去掉多余或冲突的部分。这样一轮轮缩小范围，最后再选定稿。

小A 的收敛走了四步，每一步都在做减法：

  1. AI 机器人：太接近常见形象，否掉。
  2. 课程吉祥物：更亲和，方向对了，但还没立住。
  3. skill 工具盒拟人化：有了性格来源，结构还是太复杂。
  4. 二足技能盒：去掉多余部件，定稿。

这四步去掉了机器人感、工具箱感和复杂结构，保留“陪人学习、收集技能”的角色来源，最后得到简洁亲和的二足技能盒。

05｜选主图风格

选主图时，也要考虑后面是否方便做三视图和延展。

下面两组都画的是小A。比较时，除了看风格是否喜欢，还要看轮廓和体块能否说清楚。

  • 手绘淡彩风：有手感、有温度；但这组图的体块边界偏软，继续生成时容易走形。
  • 软胶潮玩风：轮廓清晰、体块明确，在小A 的探索中更适合用作三视图和延展图的基准。

主图风格对比：手绘淡彩与软胶潮玩

06｜三视图

角色的标准身份证照

主图确定了，再补上侧面和背面，让后续生成有统一依据。

概念：把同一角色的正面、侧面、背面画在一张图里，作为后续延展的统一基准。

方法：上传定稿图，让 AI 生成三个视角，再检查造型、配色和质感是否一致。

关键约束：

  1. 手臂默认隐藏。
  2. 蓝、橙、奶白三种颜色严格匹配原图。
  3. 三视图之间统一无偏色。

小A 的三视图

三视图提示词

把定稿图和提示词一起交给 AI，明确三视图需要保持的角色特征。

以定稿图为唯一基准，生成正 / 侧 / 背三视图，等比并排、完全一致；〔角色核心特征〕；色彩严格匹配原图、统一无偏色；保持现有质感，纯白背景。

07｜写设定

设定的初稿可以交给 AI，最后的判断必须自己来。

设定把角色的性格和边界说清楚，也要考虑它面对谁、以什么姿态出现。

方法：把定稿图和项目背景交给 AI，让它拆出形象特征、写出角色设定，再由你人工补充修正。

写到什么程度算完成：名字、一句话介绍、性格、喜好、雷区五项齐全，而且能用来判断一张图是否符合角色。例如“安静可靠”就应影响表情和姿态。

第三部分｜用好 IP

08｜换装

先判断该不该换

如果衣服本身就是记忆点，换装时要格外谨慎。

有的 IP 以服饰作为记忆点。这种情况，保留标志性服饰、调整场景或动作更稳妥；配色变化也要保住角色的识别特征。

能换的时候，方向也别凭喜好定：先看这组图要用在什么场合，再决定穿什么。

换装的作用

IP 得出现在大家的生活里。

根据节日和使用场景安排服装，让角色参与当下的活动。服装与场景相呼应，它就更像一起过节、出游或毕业的伙伴。

拿几个典型的来说：

  • 毕业季：学生穿学士服，IP 也套一件，往毕业照里一站，就是个同学。
  • 圣诞：大家换上节日装，IP 跟着换，一起过节才像那么回事。
  • 夏天：大家去海边，IP 换上度假装，出现在同一片沙滩上。
  • 品牌联名：IP 穿上合作款，同时呈现角色和合作品牌的识别特征。

小A 的四套换装

换装提示词

提示词：把「不变」和「要换」分开写。

示例

小A 核心造型 100% 不变（奶白方盒、屏幕脸双眼、二足、无手臂、蓝白 + 橙）；服饰极致卡通化、去写实纹理，哑光软塑胶质感；穿学士服 / 圣诞装 / 海边度假装 / 蜜雪冰城雪王联动；纯白背景。

技巧

沿用同一张参考图和前半段的造型要求，每次只替换后半段的服装与场景，继续尝试不同装扮。

提示词中的“极致卡通化、去写实纹理”是在统一服装与角色的质感。换装后，除了看衣服对不对，也要检查造型和配色有没有变。

09｜换风格

锁住基准，只换风格

沿用同一张参考图，明确只改变画风，保留造型与配色。

做法只有两步：

  1. 先生成一张满意的基准风格图，后续所有风格延展都参考它。
  2. 上传同一张图，说明目标风格。不必重复整套造型，但要把保持造型与配色作为明确要求。

下面六种气质都来自同一张基准图：手绘淡彩、像素风、赛博朋克、LowPoly 低多边形（用较少的多边形表现体块）、油画印象派、软胶潮玩。

同一张基准图的六种风格

换风格提示词三件套

提示词围绕基准图、目标风格和背景展开，保留清楚的约束。

示例

以〔基准图：小A〕为唯一基准，严格保持造型与配色不变，仅切换整体风格为〔目标风格〕；〔背景：纯白背景〕。

可变变量

  • 目标风格：手绘淡彩 / 像素 / 赛博朋克 / LowPoly / 油画印象派 / 软胶潮玩 …

10｜数字模特

锁住主体，换掉外层

同一套「锁住主体、换掉外层」的方法，把对象换成真人模特，就是电商里的虚拟试衣。

判断方式与 IP 换装相通：先固定人物，再换衣物。约束对象也从卡通造型变成了五官、身形和肤色。

锁定模特基准：先准备一张 45° 斜侧图，再补一张三视图。将保持五官、身形、姿势和肤色不变写成明确要求。

数字模特的基准图与三视图

输入与成品

把模特基准图和目标衣物图一起交给 AI，生成同一位模特的上身图。

上传模特基准图和目标衣物图片，要求生成 45° 上身图与换装三视图。同一件衣服可以继续尝试不同角度和背景，组织成详情页展示素材。用于商品展示时，要核对版型、花纹和细节是否与实物一致。

目标衣物与数字模特换装成品

小结

  1. 怎么做出 IP：先比较方向，再收敛到定稿，用三视图和角色设定固定特征。选一个自己的角色练习，检查转到侧面或背面后是否仍认得出。
  2. 怎么使用 IP：以固定参考为依据，按用途换装或换风格，再检查身份有没有漂移。换成数字模特时，也要核对人物与衣物细节；下一课继续让小A 做表情、动作和实景延展。
