Agent与自动化

AI 一键成稿

全链路自动化产出公众号图文

第一部分｜一句话成稿

01｜成品展示

一条指令交回一整篇图文，人只出了个主题。

这条指令本身就两行，一行指定技能，一行给主题：

【@YeWriter】【@YePicture】【@gzh-design】
使用这三个技能，给我生成一篇图文结合的文章，发到微信公众号草稿箱里。
文章的主题是：“AI 不进入真实工作流，就只是玩具。Agent 的价值正在于此，它天然长在工作流里。”

你只给两样：挂上三个技能，说清文章主题，剩下的不用管。

跑完之后，对话里给出完成状态和产物入口，点开就能逐项核查。

成稿运行结果

02｜验收草稿箱

回到公众号后台打开草稿箱，封面、标题、正文排版已经就位，你只做终审。

草稿卡片：列表里多了一篇图文齐全的待发文章，封面图和标题都在，点开就能编辑。

编辑器：封面、「本文看点」引言卡、正文排版一步到位，字号、行距、卡片样式都是成套的。

人工要花一两个小时搬运和调格式的活，在这里变成了打开后台看一眼。

草稿箱卡片

编辑器排版预览

03｜手工的代价

同一篇图文，手工做完要过五道工序，写两小时，配图排版再耗一两个小时，格式还常在粘贴时丢掉。

手工流程的五个环节，一环都不能跳过：

  1. 构思写稿，先把观点和例子组织成一篇完整文章。
  2. 找图配图，翻素材库或者自己搜图，还得挑风格接近的。
  3. 排版美化，调字号、间距、卡片样式，让页面能看。
  4. 贴进编辑器，把排好的内容整体粘贴进公众号后台。
  5. 逐段调格式，粘贴过程丢掉的样式一段一段补回来。

费时：写两小时，配图排版再耗一两个小时，格式还常粘丢。

费人：公众号同学每周来一轮，大半时间花在搬运上。

这五道工序可以交给一条流水线，你出选题，你做终审。

第二部分｜接通公众号

04｜备好凭证

WorkBuddy 要替你往草稿箱发内容，先去公众平台后台拿三样东西：AppID、AppSecret 和运行环境的 IP 白名单。

  1. 登录公众平台后台，进入基础信息页，找到 AppID 并复制。
  2. 在开发密钥区重置并复制 AppSecret，和 AppID 一起交给 WorkBuddy。
  3. 把运行环境的 IP 加进 API IP 白名单，否则接口调用会被平台拦下。

三样东西都在同一页里，位置固定，找一次以后不用再找。

公众号凭证位置

05｜试通链路

别急着上全流程，先发一条最简短的文本，确认通道是通的。

我要通过 WorkBuddy，将文本【你好】发布到我的微信公众号的草稿箱，请指引我完成。

第一次它会一步步指引你：登后台、交凭证、加白名单。草稿箱里出现这条内容，说明通道、凭证、白名单三件事都对了，后面每一个环节的产物都有了落点。

草稿箱收到你好

06｜封装 YePush

把这条通道打包成一个技能，凭证只交一次，以后哪个窗口都能直接发。

帮我制作一个 skill：在 WorkBuddy 的其他窗口，避免再次输入 AppID 之类的信息，就可以发东西到微信公众号草稿箱。将这个 skill 命名为 YePush。

凭证只交一次：AppID、AppSecret 存进 YePush，以后不再出现在对话里，也不会散落在各个任务记录中。

哪个窗口都能用：任何任务做完，一句「发到公众号草稿箱」就走这条通道，写稿、做表格、整理资料都用得上。

第三部分｜装上三个技能

07｜安装技能

通道之外还差三个手艺人，写稿、配图、排版各由一个技能负责，在「专家·技能·连接器」右上角点「添加技能」装上。

自建的：YeWriter、YePicture，从本地导入，规则和风格都写在技能说明里。

现成的：gzh-design，装 GitHub 上的开源技能，直接用别人做好的排版能力。

添加技能入口

08｜YeWriter 写稿

YeWriter 是按你的风格说明书写观点长文的写作分身，专门治一眼就假的 AI 文。

观点先行，例子托底：每个观点后面跟一个具体的故事或场景，优先用真实经历，不堆空话。

拿不准就标出来：数据、引用、人名必须可验证，存疑的一律标【待核实】留给你确认。

写完自动四层自检：扫硬伤、查风格、看内容、读人味，交稿时附一份质检报告。

真实经历和好恶判断必须你来，找证据、扩写、改风格放心交给它。

09｜YePicture 配图

YePicture 读完文章自己定图，封面加章节配图一起出，一套米白纸雕风格从头统一到尾。

一图一个隐喻：把观点翻译成可触摸的物件，这篇文章的封面就是「玻璃罩里的玩具接上齿轮」。

风格锁死：暖米白纸纹、浅浮雕、柔和阴影写进规则，整篇文章的图看起来像一个人做的。

图上文字要短：生图模型写长中文容易出错，标题控制在一句以内，错了就缩短重出。

配图合集_玩具还是工具

10｜gzh-design 排版

gzh-design 把文稿变成可直接粘贴的公众号排版，样式不丢、编辑器认账。

看点卡和章节编号：文章开头的三个看点、每一节的编号和标题线，都是它加的。

关键词和结尾卡：正文里的关键词自动加下划线，结尾卡和作者签名区一并生成，粘贴后不用再补。

第四部分｜串成流水线

11｜环环相扣

稿子写完才配图，图文齐了才排版，排好版才推送，上一环的产物就是下一环的输入。

  1. 你出选题，给出主题和大致立场。
  2. YeWriter 写稿，产出一篇带自检报告的 Markdown 文稿。
  3. YePicture 配图，按文稿内容生成封面和章节图。
  4. gzh-design 排版，把文稿和图变成可粘贴的公众号 HTML。
  5. YePush 推送，把图文送进草稿箱。

换一环不动全局：想换排版风格，只换 gzh-design 的主题，写稿配图照旧。

12｜把关质量

流程跑通只是起点，每次都出得了手，靠事实、排版、终审三道关。

事实关：凡是 YeWriter 标了【待核实】的数据和引用，发布前逐条查证或者直接删掉。

排版关：gzh-design 自带校验脚本，公众号禁用的写法清零才算排完。

终审关：流水线只到草稿箱为止，通读、改标题、点群发永远是人来做。

草稿箱就是你的验收台：AI 交稿，你签发。

13｜搬进自己号

把这条流水线搬到自己号上，只需要换三处：凭证、文风、视觉。

  1. 换凭证：用自己号的 AppID，重走一遍接通流程。
  2. 换文风：把风格说明书改成自己的表达习惯。
  3. 换视觉：配图风格和排版主题按账号定位挑。

个人自媒体：读书笔记、专业观察定期更新，一个人也能稳定周更。

社团公众号：活动预告和回顾按模板量产，值班同学只管选题和终审。

先发一篇进草稿箱自己验收，满意了再谈群发。

小结

AI 不进你的工作流，它就只是个玩具。

  1. 一句话成稿：一个指令，从写稿到推送 WorkBuddy 跑完全程。
  2. 接通公众号：三样凭证交一次，通道打包成 YePush。
  3. 装上三个技能：YeWriter 写稿、YePicture 配图、gzh-design 排版。
  4. 稳住质量：事实核验、排版校验、草稿箱终审之后再群发。
